# Home Care Nursing App 🏥🩺

تطبيق لإدارة خدمات التمريض المنزلي، يشمل تسجيل الدخول، لوحة التحكم، وحجز الخدمات.
 🚀 المميزات

- تسجيل الدخول / التسجيل مع حفظ الجلسة.
- لوحة تحكم تعرض الحجوزات النشطة والتاريخ.
- حجز خدمة جديد: اختيار خدمة ➡️ تحديد موعد ➡️ إضافة ملاحظات ➡️ تأكيد.
- هيكل نظيف باستخدام  BLoc لإدارة الحالة.
🛠️ التقنيات المستخدمة

- Flutter & Dart
- flutter_bloc
- flutter_secure_storage
- Dio
- get_it
📱 كيف تستخدم التطبيق؟

1.  سجل دخولك (مستخدم تجريبي: test@example.com | 123456).
2.  من لوحة التحكم، اضغط "New Booking".
3.  اختر خدمة، حدد موعد، أضف ملاحظات، وأكد الحجز.
